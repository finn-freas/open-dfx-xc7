## Method

- Machine: Intel(R) Core(TM) 7 240H, 16 hardware threads; the open flow runs in WSL2 with 11.7 GB, Vivado 2025.2 on Windows on the same CPU. Vivado runs with its default thread count (`general.maxThreads` = 2); yosys and nextpnr run single-threaded. Other jobs shared the machine, so wall-clock times are noisy.
- Every design builds from the same RTL in both tools. A wrapped design is the upstream core inside `suite_top`: its inputs come from a 32-bit LFSR shift chain, its outputs are registered and XOR-reduced to one pin, so nothing is optimised away and the I/O count fits any package. Native designs (fir, bram, rv_big) use their own top.
- Vivado alone: `synth_design`, `opt_design`, `place_design`, `route_design`, `write_bitstream`, default strategies. Fmax sweep: run at the design's start period, then at the achieved period (period - WNS), up to 3 runs; Fmax = max over runs of 1000 / (period - WNS), Vivado's timer.
- Open flow: `flow/build_openxc7.py` (the plain `ofx build` flow: yosys `synth_xilinx -flatten -abc9`, nextpnr-xilinx, fasm2frames, xc7frames2bit). Sweep driven by nextpnr's reported Fmax the same way. "Fmax (Vivado timer)" is Vivado's timer on the open flow's netlist with every cell at nextpnr's BEL (`place_cell`, then Vivado routes: our placement, Vivado's routing). Where that step is missing the nextpnr timer is used and the cell says so.
- Area: LUT (logic LUTs), FF, BRAM (36 Kb equivalents), DSP after implementation (Vivado: report_utilization; open: cell counts of the yosys netlist). Power: Vivado `report_power` (vectorless defaults) and `ofx power` (the open estimate); `-` where the open power model is not installed.
- Placement quality, computed the same way for both tools' implementations at the start period: HPWL = sum over signal nets (no global clocks, no constants) of the half-perimeter of the nets' sites in prjxray tile-grid units; routed wirelength = used pips in INT tiles; congestion = peak and 99th-percentile used pips per INT tile.
- Score: per metric a goodness g (> 1 = open flow better): Fmax ours/Vivado; area = geometric mean of Vivado/ours over LUT, FF, BRAM, DSP; power Vivado/ours; build time Vivado/ours (total wall clock); routability Vivado/ours routed INT pips (0 if the open build failed). Weights: fmax 1, area 1, power 1, build_time 1, routability 1 (equal, user 2026-11-06). Overall = weighted geometric mean over the metrics present; verdict better if >= 1.05, on par if >= 0.95, else worse.
