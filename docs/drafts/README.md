# Upstream drafts: index (NOTHING here has been posted; posting needs the user's approval)

Every patch below was compiled and tested offline on 2026-11-05. None has run on hardware. Details, evidence and log paths are in each .md.

Release ofx 0.1 (2026-11-06, docs/install.md "Release ofx 0.1"; which drafts are on by default: docs/ofx.md "Release defaults") ships these drafts through the installer, unchanged here: the
27 nextpnr drafts from pblock-xdc to xadc as `install/patches/nextpnr/0001-0027` (conflict resolutions in
`install/patches/rebased/`, docs/install.md), the three yosys drafts as `install/patches/yosys/` (built as plugins),
the five prjxray-db files as `install/patches/prjxray-db/` and site_type_XADC.json as
`install/patches/nextpnr-xilinx-meta/`. Not in the release: nextpnr-area-pack, nextpnr-lut-perm-timing,
nextpnr-muxf-const-inputs, yosys-xilinx-area-opts, litex-sim-analyzer-csv (not in the list given for this release).

Order of dependence: pblock-xdc → router-region → {pblock-replay, pblock-routethru}; router-region + pblock-replay +
pblock-routethru → partition-pins → pblock-lutff → carry-replay-order (variant `partpin`) → partition-pins-route
(variant `partpin2`) → partition-pins-pinfeed (variant `partpin3`). router-region → nextpnr-xdc-timing (variant `xdc`) → nextpnr-xdc2-constraints (variant `xdc2`, with the yosys-xilinx-asyncreg plugin) → nextpnr-timing-report (variant `timrep`) → nextpnr-ologic-iob-sdr (variant `xdc3`). qorfix stack (dsp-mask-areg, iserdes-const-pins, muxf7-mixed-loads, hardblock-timing) → nextpnr-dsp-cascade-place (variant `qordsp`; nextpnr-cell-timing-cal only changes the chipdb generator). qordsp → nextpnr-lut-perm-timing (build `qorperm`). nextpnr-cell-timing-cal → nextpnr-route-timing-cal (generator only). `ofx` series (0001-0011) →
io-buffer-params → mmcm-base-ties → bufh-region → diff-term → cfg-in-use → clkout-unused → fifo (variant `ofx-prim`,
checked by toolchain/buildenv/check_prim_series.sh) → xadc (variant `ofx-prim-xadc`). `ofx` series + hardblock-timing →
nextpnr-placer-tuning (variant `place_v4`, worktree build/src/nextpnr-place). qordsp stack → nextpnr-muxf-const-inputs → nextpnr-area-pack (variant `qorarea`). The rest are independent.
